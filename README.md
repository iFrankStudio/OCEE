# OCEE-0 赛博生命培养世界：规范包

**版本**：0.1.0 · **状态**：设计草案（Draft） · **日期**：2026-11-17

本规范包来自“为现实数字世界培养具有强自适应与自我创造能力的赛博生命”的思想实验，作为**独立研究路线**提出，不对正在运行的 CL 系列实验做任何修改，也未声称已经完成实现或验证。

   确定性世界状态机、资源计量、六个交互原语、A/B/C 异构节点、未知协议可发现性、事件日志、安全权限与内核验收。

   未知远程计算服务、可学习的协议家族、四个对照组、正式样本与预算、能力形成判据、跨协议迁移、统计及审计。

## 一句话的研究目标

**不是让程序在虚拟世界里取得高分，而是检验：环境交互能否促使个体创建并保留新的可复用算法能力，随后将该能力迁移至未见过的异构环境。**

## 本阶段的约束

- OCEE-0 不接入公网、真实生产系统或物理执行器。
- 不预设生命值、强制繁殖、定时死亡、奖惩分或必须探索的行为。
- 内核稳定、个体可变；内核的资源计量、权限及独立评价器不可由个体修改。
- 不把运行任务表现直接等同于生命出现；区分环境适应、工具创建、迁移、开放式演化。
- 区分**原生型 O**与**能力种子型 S**；前者观察自发行为起源，后者检验培养机制是否能形成累积能力。
- 未经运行验证的参数一律视为**待校准默认值**，不是实测结论。

## M0：第一个可证伪里程碑

以 E001 为基础，首先证明如下现象能否在可重放实验中出现：

1. 个体起始不具备目标远程接口的专用适配算法；
2. 个体能通过可审计的环境交互形成有效的协议使用方法；
3. 个体自发生成能在多个输入上复用的新程序结构；
4. 所获得的能力在结构不同的新协议环境中产生可统计、可复现的优势；
5. 关键成功轨迹经过去除工具/回退版本的反事实检验；
6. 不存在内核代替决策、隐藏答案泄漏、评价器被篡改或不合理的额外资源。

成功仅说明**特定条件下的可累积适应机制**得到支持，并不意味着已经证实赛博生命出现。

## 实施建议：严格按依赖顺序

**P0 定义冻结** → **P1 确定性世界内核** → **P2 个体 VM 与版本控制** → **P3 未知协议服务及独立校准** → **P4 四组对照** → **P5 锁定并运行 E001** → **P6 审计与统计报告**。

每一阶段先验收必要不变量，再进入下一阶段。仅保留关键流程、权限和确定性测试；不要为无关小修复堆积重复测试。
