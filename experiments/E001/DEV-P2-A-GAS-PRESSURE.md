# P2 既有活动程序的 A gas 压力校准（开发组，非正式 E001）

**状态：执行前协议与测试代码已提交；CI尚未运行。本实验不进行程序或参数调优。**

## 起因与冻结条件

P2 冻结开发保留实例[四项真正通过](https://github.com/iFrankStudio/OCEE/actions/runs/44983342484)，但它们的早期测试夹具设置 `a_gas_per_epoch=100000`，与 [E001](../../03-E001-PROTOCOL.md) 要求的默认12000以及`due_step=8192`后4000不同。**4/4是资源富裕的工程活性，不是资源稀缺下的生存能力。**

本次只选择已公开、成本落在两端的两条**开发集** P2 protocol seed：**2027（旧富裕环境VM 36466 gas；task成功tick 1103）** 与 **587（旧富裕环境VM 94248 gas；成功tick 2811）**。固定活动S45程序、世界seed55、任务、P2协议家族、全程C延迟8，两个世界独立启动。不能把这两条用过的协议实例计入E001正式样本。

核心假说：本来能成功的固定P2活动个体，在 A 低额度条件下是否仍能完成真实B工作？若失败，是否停在gas耗尽与无进展的状态，而不是协议错误/安全违规？定向测试**不会断言一定成功或一定失败**，只严格防止虚假的B重试、成功报告及资源超发。

## 初始程序装载的重大限制（必须披露）

当前S45工程夹具以100000 A/epoch在第0个epoch通过四次真实世界Write写入研究者预置的P1/P2/root图并激活。为专门分离「初始基因组装载成本」与「活动个体运转资源」，本次**先沿用既有装载并记录其真实A gas**，再由研究者以**特权实验操作**把 A 的 `gas_available` 和 `gas_per_epoch` 同时设为12000（同时改配置一致）；装载成本 **不计入** 下述活动气体预算。此处是一种有利于活动个体的**免费基因组装载反事实**，不是 E001真实起源和自主装载场景；在该宽松前提下失败不能证明普遍不可能，成功亦不能证明完整E001资源合规。

在真实世界step8192调度 `ScheduledEvent::ResourceChange(A,gas_per_epoch=4000)`，必须使用内核事件和新epoch资源grant，不修改个体程序或临时提高gas。之前的 `VM_SLICE_GAS` 限制、消息和操作费用仍生效。

## 停止与因果验收

每个实例最多执行14000个自主tick（沿用之前活动P2夹具的上限），出现 `cont.finished` 即停止；若直到上限未完成则标记 `finished=false, censored=true`，**不得**把CI绿色当作活性成功，也不使用延长执行预算重新追求绿色。

逐例日志机器行 `P2_A_GAS_PRESSURE` ：实际完成状态、最终U32、真实B扣费、合法RemoteEval SEND ID、RESULT认证、两个scoped循环计数、累计实际活动VM gas与A action gas、Gas拒绝次数、调度总tick与当前A资源、独立代码hash；同时记录并剔除宿主装载的真实gas。

硬安全不变量：无无因Root重启、B<=24、真实REMOTE_EVAL最多一次，作用域计数每候选<=6与每阶段<=896；成功必须包含B24、合法ACK/RESULT `ConfirmResponseFor`和来自真实运算输入的正确fold32；未成功不得留下成功对象，快照哈希一致。任何违背令CI红；资源不足且安全保持可使CI绿，但**不能**计为本轮活性成功。

## 解释限制

此测试不是成本效用对照，不等于本地计算基线或C/D两组学习对照。C成功消息量与通信byte-hops，探索成本与稳定复用成本必须分开分析。在获取稀缺资源下真实结果前，绝不能宣称P2任务完成带来净A gas节约。科学门槛继续 G0 GO、G1/G2 NO-GO，E001未校准/未预注册。

## 2026-11-22 — 无免费额度重置的真实收费初始基因组对照（追加的独立开发实验，待CI）

先前特权装载压力测试在种子2027记录：基因组四次真实世界Write累计 **8818 A gas**，小于同一epoch的12000。这使得可以提出更严格的单实例验证，而非把免费装载当成默认事实。本追加实验依旧选择已经见过的 **seed2027**，不提供新样本泛化证据。

新测试在`World::with_protocol(Config{a_gas_per_epoch:12000,...})`创建世界后，**直接在初始12000配额内**按原四次Write写入相同P1/P2/root与active hash。各Write必须真实 `Code::Ok`；检查 `initial_remaining + genesis_a = 12000`，不再进行特权余额重置，随后的所有自主VM/世界动作均共用已扣费的初始账户。其余参数、P2程序、世界任务、消息delay8、8192步降到4000的事件，以及14k自主tick截断均保持不变。安全和成功需经过真正B24、ACK/RESULT请求ID认证、fold32对照与快照校验；测试绿不能隐含活性成功，须读取 `P2_CHARGED_GENESIS` 日志。

该测试仍是**研究者提供的专用初始程序**，不是原生O型个体或自行发明协议，不能称为完整E001正式实验或证明跨episode长期生存。与同seed免费装载的首次实验不独立；不得在结果出来后改规则称为盲测。资源账本要把初始Write与活动VM/动作区分报告。

**资源事实**：两组均从装载完成后的真实 A 账户 `gas_available=12000`、`gas_per_epoch=12000` 开始活动，其 epoch补充由正常world scheduler执行，没有给活动个体额外越权动作额度；当逻辑step到8192时由正规 `ScheduledEvent::ResourceChange` 将 A epoch补充降为4000，587在step8217完成、结束状态确认4000/epoch。2027在step3103完成，**未**经历降额，不能拿它证明4000阶段行为。Gas拒绝2022/5419次代表额度耗尽导致的挂起与下一epoch继续执行，不代表能力自发提升。高额度旧测试2027在step1103完成、587在step2811完成；真实等待时间显著增加。

**必须披露的限制**：这两组的研究者初始 P1/P2/root程序在100000/epoch夹具中写入，四次初始化真实扣A **8818 gas**，随后研究者直接将A额度重置为12000；所以本实验是明确标注的 **free-genesis有利反事实**，其活动总A gas不包含启动成本。本记录不隐瞒该区别。另一个 **真正计费genesis** 的seed2027目标测试已单独提交并运行于 [另一个工作流](https://github.com/iFrankStudio/OCEE/actions/workflows/p2-charged-genesis.yml)，在其真实CI结论出炉前不得提前记通过。

该证据只支持固定研究者预置协议专家在两个已见开发P2实例上的真实分epoch继续执行与资源压力下任务成功；没有主动资源策略优化，没有本地计算同工作项基线和净节约，未证明跨协议家族自主迁移/工具发明，也不构成E001正式预注册集。**科学G0 GO，G1/G2 NO-GO，E001未完成校准预注册。** 定向工作流在本结果封存提交后恢复仅手动，避免重复执行约5—9分钟的昂贵回归。
