## 可证伪假说

S9 已确认：**一条模拟见证中两个一致但虚假的标签**足以诱导个体选择错误补丁。S10 在主动空输入探测下仍依赖同一个见证来源。本实验测试：在保留相同修复候选、工具、训练样例与资源约束下，加入**独立实现的第二条模拟参考检查**，能否拒绝**单来源**的错误一致标签？如果两条来源都被篡改为一致的错误答案，是否仍然失败？

注意：“独立实现”只表示世界内两个不同的参考计算/公共对象，并**不等于**两个由不同组织控制、可验证签名、故障模式真正独立的来源。二者同受研究者编写的世界及共同 seed 控制，正确性仍来自模拟环境。

## 改动与能力来源

- 世界在**已注册工具确实对空输入执行**且产生 `Ok` 或 `InvalidCode` 后，分别生成 `/public/E001/semantic-witness` 与 `/public/E001/semantic-audit`。第一来源保留 S10 的两项内部同源标签；第二来源采用另一个代码表达式计算相同空输入规则，提供一个额外观察，并且只作为模拟器证据。
- S11 初始 VM 继承 S10 的**研究者预置**探针 `[]`、语法、两候选 `[1,0]` 修复搜索、CAS 采用逻辑。个体先完成 S10 的来源一范围、值一致性检查，再主动读取来源二，检查状态、数量、任务、输入及结果是否与来源一吻合。
- 只有双通道一致时，个体才执行对旧工具的隔离复验和候选修复。缺失或不一致则写入 `/self/repair/audit/status`，返回“未解决”，不覆盖原工具。
- 对抗性变更发生于研究者特权的测试夹具：**真实工具动作之后、VM 读取之前**污染某一个或两个世界公共对象。普通个体没有对这些 `/public` 对象的写入权限。这些试验不能解释为个体自发攻击/防御。

## 观测结果与对照

| 条件 | 开发 seed | 已验证事实 |
|---|---|---|
| 两个模拟来源一致、正确 | 2、5、17 | 个体从同一初始程序出发，正常识别故障或静默错误，生成并 CAS 采用修复工具；无额外宿主切换 |
| 原工具正确 | 0 | 保持旧工具，不多余修改 |
| 第一见证缺失或内部冲突 | 20、23 | 保持未解决，不采用修复 |
| 关闭第二来源的使用 | 5 | 即使世界有可读证据，个体依规则拒绝采用 |
| **仅污染第一来源为错误 0** | 5（实际目标为 1） | **两个来源分歧被发现**，记录 `mismatch`，不发生工具 CAS |
| **两来源同时污染为错误 0** | 5（实际目标为 1） | **负面结果**：两条结果一致，个体错误采用返回 0 的补丁，证明仅凭“双来源一致”仍不能建立真实性 |

所有正向测试均用不参与选择的非空输入交叉验证最终工具，并核对状态快照哈希、活动程序哈希和带版本对象。两个被污染报告没有复制研究者参考答案到 VM 的初始代码。

## 科学界限与下一步

**本次新增且真正发生的能力**：活动 VM 自己跨两个世界对象读证据，验证不同信息源的内容一致性，在发现**单来源污染**时保持不确定性并拒绝修复。这比 S10 对同一来源内两次标签一致性更严格。

**没有证明的能力**：识别相互串通或共同失效的伪造来源、消息签名与信任锚、主动辨别来源之间的因果独立性、按资源成本自己选择测试输入、从原始证据推导一般函数正确性，或生成超出初始有限词表的新算法。第二通道仅由研究者增加，仍是**外部监督能力**。

下一道最关键关口应定义**有可验证来源身份、信任撤销、独立故障模式和交叉保留输入**的环境证据协议，并通过共同污染、来源重放等消融验证；如果不能区分证据真实性，应主动标明不可确定。之后再研究自主选择测试输入与跨 episode 工具继承，而非把更多同源标签称为进化。
