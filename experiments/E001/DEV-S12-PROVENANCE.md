# E001 开发实验 S12：模拟证据来源声明与程序版本绑定

- 基线：S11 两条模拟参考通道；资源限制保持每 epoch 12,000 A gas、256 KiB 存储。

## 假说与实施

S11 对单通道数值污染能拒绝，但并不检查证据是否属于**正在验证的不可变程序版本**，也不检查来源角色。S12 为世界发布的 `BoundaryWitness` 增加 `source_id` 和 `subject_program_hash`；来源分别为 `sim-boundary/v1`、`sim-primary/v1`、`sim-secondary/v1`。发布只发生在对应注册工具的真实 `EXEC` 之后，且原有 gas 拒绝不发布规则不变。S12 活动 VM 在使用两份模拟报告前分别检查其来源声明与正在检验的程序哈希，不符合则保存 `source_mismatch` 或 `stale_program` 并拒绝 CAS 修复。

新增两个聚焦测试：正常种子与来源标识/哈希污染的端到端试验；关闭来源/版本检查的 S11 对照与双来源同时伪造的负面试验。研究者夹具在真实执行后、个体读取前修改公共报告，普通个体不能写入这些路径。

## 能力来源及不可声称的结论

来源标签、校验算法、候选修复语法、空输入探针、双通道与所有参考语义均由研究者预置。**字符串来源标识不是签名**，哈希绑定只对诚实发布或未同时伪造元数据的情形有效；相同版本的旧报告、两条通道同时伪造一致数值与元数据仍可能被接受。世界审计链不等于外部独立信任锚。没有自主推断来源身份、认证、跨 episode 迁移、陌生 P1/P2 学习或新算法发明。
