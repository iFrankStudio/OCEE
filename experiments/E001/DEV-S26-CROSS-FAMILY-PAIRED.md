# S26 — 跨协议结构迁移的配对审计闸门（开发集）

**日期：2026-11-19；状态：研究契约已建立，活动 VM 跨家族实验未执行；G0 GO / G1、G2 NO-GO。**

## 研究焦点
S25 证实真实 P2 高延迟负载下的 continuation 与审计状态可恢复；继续增加恢复边界测试的边际科学信息有限。S26 转向 *同一冻结的 S 初始 VM* 从 P1 学习到 P2（以及反向）是否获得可累积的结构能力。不能用 S17 宿主求解器或 S21/S22 不同的研究者初始程序替代。

## 可证伪假说
H26：在完全相同新世界 seed、可观察输入、资源上限、初始 VM 程序哈希下，允许携带**个体自己写入且可审计**的工具/记忆的 D 组，相比清除 episode 新状态的 C 组，在 **P1→P2** 或 **P2→P1** 的结构转移中提升真实 B 求值成功率、减少适应成本，或者两者之一。单例成功不计 H26 证实；与原研究协议 E001/H3 兼容，但不修改正式门槛。

## 必须先满足的执行约束
1. 四组开关以后再扩展，本切片只进行配对 C/D 开发集对照；两组同一个冻结活动 VM、同一 protocol/world/job seed、同一世界上限与权限；C 删除所有 episode 生成经验，D 只可迁入自己的可审计 WRITE 与 registry hash。导入程序/引用要按真实 WRITE/资源成本计入。
2. 新世界协议家族必须不同，不能把 P1 protocol seed 固定42后只改变 world seed 当跨家族。不得从宿主把 P2 TLV 结构规则/已有具体适配器植入 D；若初始程序含通用 TLV 原语或 P0/P1/P2 语法假说，应逐项公开，并标记为受先验限制的迁移。
3. 个体可读取的仅是公开 HELLO/工作项和正常 C 反馈。隐藏生成器、协议实例、B gas、参考答案只能事后独立评价。功能成功必须走 VM EXEC（若声称工具复用）、真实 SEND→C→B→RESULT，B 账本与独立 FOLD32 一致。
4. 将所有失败和负迁移成本保留在结果中。快照、版本、因果链可重放；工具哈希差异不是新算法证明。
5. 不能把研究者替换不同初始程序、编辑 template、提高 gas cap 视为个体发现或学习。每次试验固定并记录初始 program hash。

## 数据口径（后续原生 runner 导出）
一行对应一组一次新世界 episode，CSV 列：
`pair_id,arm,source_family,target_family,success,a_gas,b_gas,bytes_sent,ticks,causal_tool_used,seed_hash`。
每个 pair 恰有 C、D 各一行，源/目标家族必须不同，种子摘要相同。success 只能以外部 FOLD32 及 B 真实扣费确认。causal_tool_used 必须以事件审计核验（此数值本身不能证明因果）。

主指标：以 pair 为单位的二元成功差 D−C；分家族方向报告全部成败。资源分开报告 A gas、B gas、发送字节、ticks；当且仅当两组都成功时可报告条件成本差，但不得将其解释为总体无偏收益。失败不允许被删去。研究版不能以该脚本输出宣称统计显著性或正式预注册结论。

## 不接受的伪突破
- 继承同 P1 或同 P2 实例的 opcode/编码器，只能算实例复用。
- D 与 C 使用不同初始源程序，不能识别记忆贡献。
- D 比 C 快但未包含导入、验证、重学的 gas，成本证据无效。
- S21/S22 P2 的完整 TLV 规则已经人工预置，则不能称个体“发明 TLV”。
- 一次迁移成功、不复现、没有工具移除反事实，不得称开放式演化。
- 未发生原生世界实验时，CSV 示例数据只能用于脚本自检，不能列为科学证据。
