# DEV S29 — Finite transform settlement (development contract)

Resource-aware evaluation #45396685822 3/3; utility frontier is offline, not an actual reward. First implement narrow opt-in single-actor, single-offer economic primitive before any new organism experiment. Existing default worlds/serialization/fees/behavior unchanged when disabled.

Trusted environment constructor explicitly allocates a finite independent initial payer endowment of at most 4096 A, and one immutable public TransformTask with single lowercase ASCII ID and held-out input 1..255 bytes. Positive price <= endowment. No VM operation to configure, replenish, change price or inspect private escrow. Normal A epoch grant/reset unchanged; escrow survives epochs and is not replenished. This is an explicitly configured resource source, not a second actor or endogenous market; total system is still open to existing grants. No payout is minted at settlement. A successful normal create-only Write to the exact bound /self/outcomes/s29-offer-<hex id>, owned by actor1, version0, 280-byte receipt containing independent correct transform(seed,input) byte, SHA256 exact input, and canonical padding 0x55, while public offer still matches original trusted bytes/version0, settles once. No dependence on Exec status or registry: correctly delivered result is sufficient, not proof of algorithm discovery. Wrong/malformed/stale receipt or unrelated action can never pay. Ordinary write semantics unchanged (a wrong create can consume the one submission slot; this is intentionally a single-shot contract, not a repair protocol). Only normal Write qualifies, not WriteIndexed or host fixture insertion. Actual fee must have been paid first, quota/CAS/Gas rejection cannot pay. Exact checked debit of price from finite escrow and credit to A spendable balance, record paid step and amount in snapshot/audit; if overflow cannot transfer, fail closed with no payout. No additional correctness feedback beyond actual balance/credit, no free answer oracle. Fixed bounded verification workload charged to environment (not modeled as organism gas); document this cost omission. No new VM permission.

Audit ActionResult optional zero-omitted a_credited field; all legacy result constructors zero. Exact tick hash and replay; no payout at epoch refresh, no hidden top-up. For same-epoch transitions check available A + escrow decreases only by actual A fees, and grant boundaries separately account actual reset. No implicit carryover of A, no claims of self-sustaining ecology. Tests: disabled legacy write; valid settlement, fee-before-credit, read real spendable balance and spend previously unaffordable amount; replay and snapshot; duplicate CAS/overwrite no second payout; wrong result, wrong digest/padding/path, changed public object, Gas and Quota, non-owner; epoch reset preserves unspent escrow and no re-credit. Keep regression suite. No E001 formal protocol changes. G0 GO/G1,G2 NO-GO.
