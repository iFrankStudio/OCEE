**Frozen before implementation; native 3/3 verified.** Baseline complementary six jobs #45312329768 plus distinct v2 nine jobs. A fixed one-round negative memory can miss newly available reclamation. Test a minimal transition from externally submitted artifact to **VM's own paid task attempt and actual receipt-conditioned maintenance**. This is a researcher-authored task and policy, not self-generated goals, learning or autonomous access outside the world.

## Paired design, seed129 pilot
Use the genuine P2 seed129 post-repair world and v2 target rule, with all version pins. Preinstall both task-policy roots and pin them in one common researcher fixture, no target hash literal in either. Activate existing dry-run cooldown root, run until its actual first bounded unsuccessful catalog/index/GC episode creates paid b1/v0 memory. No synthetic memory injection. Before forking, configure free capacity195 initially, grant a natural epoch if needed to ensure finite A. All branches inherit this exact experience and actual root inventory. Both new roots activated by equally priced real read/CAS; compare from activation-completed snapshot, fixed horizon +90 world steps, no host-selected action within VM execution.
Both roots first issue real WorldCall::Write for a 280B synthetic task artifact (create CAS sentinel). On Ok return success, no maintenance. On actual Quota receipt, read real negative memory. Non-Quota failure must fail closed. With b1, FIXED_COOLDOWN resets via existing paid CAS and terminates after one allowed maintenance round; QUOTA_OVERRIDE instead enters existing paid resource gate, dynamic catalog, real index and bounded GC in that same opportunity. A successful GC leads to a real retry of the exact 280B artifact write and only its Ok returns success. Both still use the resource threshold and legitimate reference checks. Exhausted search writes true b1 memory and terminates. Neither gets a host-provided target or permission bypass. One bounded attempt, one possible GC, one possible retry. Program bytes, memory, gas, physical storage and index post-tick serialization measured, separately from exogenous setup.

Three frozen matched arms, seed129: RELEASED: before activation researcher pays 64B→64B CAS release of v2 verified orphan, keeping free195B. Both first writes Quota. FIXED skips and fails, override reclaims actual target and own second write Ok before horizon. PINNED: same paid CAS retains real hash; both first writes Quota, fixed skips, override pays a scan but must not delete and task remains failed; report excess A, no claim universal advantage. SPACE: same paid CAS retains hash, researcher fixture increases capacity to actual used+512B before branch fork; both first writes Ok, no index, no memory change. For each arm independently restore branch start and run exact same ticks; audit and snapshot must match, true P2 B20 unchanged. All remaining live versions and registered tool protected. Report actual task attempts/results and fees from audit, maintenance cost separately from task fee, root hashes and exact common snapshot, external activation/fixture cost outside study interval. If horizon or A inadequate, preserve failed native result, not tune in retrospect. No generalization beyond these finite synthetic controls. G0 GO, G1/G2 NO-GO; formal E001 uncalibrated/unpreregistered.
