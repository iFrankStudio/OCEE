# OCEE S33 — 公开反馈驱动的程序结构深度选择及跨家族 B 应用

**2026-11-20；开发/探索性试验，非正式 E001 确认性实验。基线 G0 GO，G1/G2 NO-GO。**

## 为什么不是重复 S7/S8 或 S30
S7/S8 已经在研究者指定异常输入和固定保护结构下实现了 PrependBlocks 的受限修复。S30/S32 让 VM 在单一固定的“两一元+一二元”拓扑中选择18种算子组合，且其结果真正进入 B 第四个操作数。S33 研究的是**拓扑深度本身能否依据任务标签发生不同选择**：在旧的4条指令图之外，提供一个6条指令图，追加 Len(input) 和 Add(base,len) 的额外计算阶段。两者不是同一个语法实例，后者确实多出一个依赖层。

## 任务与可证伪设计
研究者在各世界启动时**明确安装只读公共开发任务** /public/E001/compose-depth，类型仍为原有 TransformTask。它的两组公开标注样例是 input [13,7,11]、[18,9,4,6]，隐藏规则在世界 seed 为偶数时返回既有 hidden_compose(seed,input)，在奇数时返回 hidden_compose(seed,input)+Len(input)（U32 回绕）；保留输入 [7,8,9,10,3,1] 的预期答案不出现在公共任务。该任务是**原生测试宿主在世界初始化阶段创建的开发 fixture**，不是系统普遍自动生成的新世界任务；隐藏参考函数也只用于创建公开标签和实验结束后的独立验收，活动 VM 不读取 seed、奇偶状态、隐藏公式或结果。
由于内核 Read ACL 是严格白名单，S33 仅将这个明确路径加入允许读取的列表，不改变 /public 前缀其它权限、/self 写入权限、B 服务规则或原有任务内容。首轮在没有加入 ACL 时真实发生 Denied，属于环境授权失败，不能当作模型学习失败。

## 活动 VM 的搜索算法与先验
- 冻结同一个初始 root、同时装载 P1/P2 两位研究者提供的专家程序，在世界之间不因 seed/协议类别预先选正确候选。活动 VM 观察公共标签，受限 RepeatBounded(36) 遍历 18 个浅层候选，再遍历 18 个深层候选。两个骨架都由研究者预置为 JSON 字节；活动 VM 使用 JsonIndex/JsonFieldBytes 按当前候选索引选择骨架，通过 RewriteOp 三次替换两个一元算子和一个二元算子并真实封存/Exec，通过两个样例数值比较决定接受哪个图。
- 浅层程序内原型为 ConstU32 + unary1(Bytes) + unary2(Bytes) + binary(unary1,unary2)；深层新增 Len(Bytes)、Add(binary,Len)，返回值由第4个运算寄存器变成第6个。**研究者仍固定了两种结构、搜索顺序、额外阶段的 Len+Add，不是通用开放长度的自动合成。**
- 来源 P1 世界 seed1 / 10 对应目标 P2 世界 seed19 / 28：每对 seed%18 一致、规则奇偶一致，且共享相同初始 root 和协议 seed42；P2 必须对来源 VM 真实生成的程序按本目标公共双样例重新验证，并在本目标新输入上 Exec 得到真实 B 第四个 U32，然后通过 S31 长度工具准备 count4，两位专家真正 READ、SEND 到原有 C/B，B 返回独立可核验的 FOLD32 结果。
- **浅层关闭机制消融**：只把同一搜索的循环上限减为18，维持相同公共深层任务、其它程序与资源设置；对于 seed19 的深层目标，旧18种浅层图不应通过两组训练标签，不能产出真实第四操作数或 B 任务。这是研究者更改搜索空间的功能消融，不是完全相同状态的反事实。
- **等成本假注册表**：与正常继承导入完全相同版本字节、真实两次 WRITE 和收费，只把 registry key 改为不可发现的同长度别名；P2 必须自己重新搜索出深层图，真实完成 B，正常继承因避免候选搜索应该有更低 A 消耗。不能把 sham 碰到同内容哈希视为继承因果证据。
- **错误拓扑恢复**：把来源 seed10 的浅层图注册给深层目标 seed19，目标必须用本地标签识别失配，重新搜索、生成深层新版本，再以正常受费 CAS 把 registry v0→v1，最后依靠新图输出执行真正 B。

## 科学边界
这个实验最多验证**在研究者给定的两个拓扑与36个有界组合中，个体基于公开结果选择结构，并实现跨家族继承、错误结构恢复与远程任务应用**。没有提供任意深度生成语法、自动目标提出或无界结构搜索；任务的世界内核是研究者可控本地模拟 C/B，并未使用真实互联网。样本只是两个开发性种子配对及对照，不构成统计显著性或 G1/G2 的确认性证据。
