# OCEE S36：由活动 VM 选择区别性探针，向模拟环境主动请求反馈

**2026-11-20，开发探索实验；G0 GO，G1/G2 NO-GO；未预注册确认性 E001。**

## 目标与既有局限
S35 证明，仅靠两条公开样例会错误识别程序，即使真实远程 B FOLD32 成功，也可能使用语义错误的第四操作数。S35 的第三条标签由研究者预先发布。S36 希望改为**活动 VM 选择探针输入、主动付费查询模拟环境、根据反馈排除错误程序**，并在跨 P1/P2 继承过程中使用同样的验证门。

## 新增的真实世界机制
- VM 新增 `WorldCall::Probe(Bytes)`，经原生 VM host 成为世界内核 `Action::Probe{actor,input}`；只有安装了 task_id 为 `s36-interactive-probe-v1` 的明确定义开发任务才允许向模拟环境查询。
- 探针非空、最多8字节、每个世界最多一次成功查询；成功收费 `40 + 4×输入长度` A gas。查询原始输入、成功/失败反馈和收费都进入世界 audit，并在世界状态中持久化 `probe_count`。超额返回 `Quota`，非法长度返回 `BadRequest`，没有开发环境返回 `Denied`，没有执行费用时返回 `Gas`；拒绝不会给出隐藏答案。
- 内核收到实际请求后，才使用研究者隐藏环境规则 `hidden_compose(seed,input) + floor((seed%54)/18)×Len(input)` 计算 TransformExample 标签并返回；VM 不能直接调用隐藏规则，也不能事先 Read 到该输出。B 是本地模拟协议服务，没有任何真实互联网权限。
- 对未查询世界，`probe_count=0` 的 serde 采用默认值并省略序列化，避免破坏先前未查询世界的规范状态字节；成功查询后的 probe_count=1 进入 state hash 和 snapshot。

## 冻结 root 的运行时算法
1. 所有 P1/P2 正常世界使用同一完整 root 与同样预装的专家库，根程序基于 S34 的54候选增量语法进行 RewriteOp/AppendInstructions/真实 WRITE 和双标签 EXEC；来源 P1 实际生成的工具可经受费版本与注册 WRITE 迁移至 P2。
2. 一个已在两条公开训练样例上过关的候选（包括导入的旧程序）先 READ 自己的 `/self/evidence/s36-active-probe`。有缓存则直接用已取得的标签继续执行该候选验证；明确 NotFound 时，才启动主动查询。其它读取异常 fail-closed。
3. 研究者只提供两种候选探针输入 `[1]` 与 `[7,8,9]`，以及用 `Len` 与 `XorFold` 作一对仍符合现有证据的参考假设。VM 先计算第一个输入上两种预测是否有差异；若相等，才计算第二个。默认第一个无法区分，第二个 Len=3 与 XorFold=6 不同，VM 才选择 `[7,8,9]` 执行真实 `WorldCall::Probe`。如果没有任何输入可区分，则不浪费环境查询而直接 fail-closed。
4. 查询成功后，VM 以正常受费 `WorldCall::Write` 保存返回的 TransformExample 到自有证据对象，随后真实 `WorldCall::Exec(candidate,selected_input)`，将候选 U32 和刚获取的标签比较。未通过的候选继续被淘汰，后续候选从同一缓存验证而不重复花费查询额度；错误继承使用原 S30 的搜索回退与注册表 CAS v0→v1 修复。
5. 通过后维持 S32/S31 的任务因果路径：选中组合程序输出对目标世界未见字节输入的 U32、写作真实 B 第四操作数，独立生成 Len 工具写 count4，P1/P2 专家真实读取、编码并发送到 C/B；独立研究端再核验 B 返回以及所学程序输出的隐藏任务正确性。

## 可证伪原生判据
- 三种深度 0/1/2：来源 P1 seeds 1/19/37 到目标 P2 seeds 55/73/91。候选版本 WRITE 数预期为 2/20/38，正确程序必须跨家族真实导入并再次验证，源/目标各有**一次真实 Probe**，输入 `[7,8,9]`、费用52 A、probe_count1、真实单次缓存 WRITE；来源查缓存两次、目标一次，实际远程 B gas24；根 SHA 在各世界一致。
- 原 S34 不主动查询的控制应在同一训练歧义下产生**B 正常成功但第四操作数语义错误**的证据，避免把 FOLD32 算术正确混同任务学习正确。
- 由旧 P1 真实生成、仅通过前两条标签的错误程序，导入 S36 P2 后必须通过环境查询检测错误、缓存查询结果、重新选正确程序、受费 CAS registry v0→v1，再完成实际 B；不能由研究者替换工具。
- 人为将查询额度预先耗尽的世界尝试 Probe 后收到 Quota，必须在无缓存情况下终止且 B0，没有伪造结果。这个实验干预不是自主恶意攻击或真实资源事件。
- 目标两阶段同导入成本的可见继承/不可见 registry sham 都只允许**一次**环境 Query，B 都要真实成功；正常继承应节省重复搜索的 A 成本。
- 世界内核直接接口测试验证：无任务 Denied，空/超长输入 BadRequest，有效请求返回匹配输入的隐藏环境标签并收费52、二次请求 Quota 且不计费，世界 snapshot/hash 正确。
- 探针银行反事实：当研究者将有区别度的 `[7,8,9]` 放在第一个候选位置时，VM 应直接使用第一个而非固定选择列表第二项；真实 B 运算仍成功。

## 科学边界
本轮主动性严格有界：两种比较的参考原语、两个拟议探针、比较方法、后续搜索和单次查询额度都由研究者预置；没有开放搜索任意输入、自动学习假设的概率分布、最优信息增益、对抗式证据验证、独立真实网络服务适配或生物意义的开放式演化。环境对查询返回的是研究者提供的可信标签，未授权世界不能使用该功能。这只能验证有限任务中的主动查询与有效证据使用。**G0 GO，G1/G2 NO-GO。**
